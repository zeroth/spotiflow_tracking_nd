# Phase 2 — 3D Spot Tracking Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A *Spot Tracking* napari widget that links the Detection widget's spots CSV into 3D tracks with trackpy, writes a tracks CSV + JSON sidecar, and shows a calibrated Tracks layer.

**Architecture:** Pure linking logic in `_tracking3d.py` (pandas + trackpy, no Qt); a `TrackingWorker3D` QThread in `_workers3d.py` that streams `trackpy.link_df_iter` frame by frame for progress and cancel; a `TrackingWidget3D` driven by the existing `RunStateMixin`. Linking happens in voxel coordinates with a per-axis search range; µm/s appear only as extra columns and as the layer's `scale`.

**Tech Stack:** trackpy ≥0.6 (verified 0.7), pandas, numpy, qtpy, napari 0.9, pytest + pytest-qt.

**Spec:** `docs/superpowers/specs/2026-10-05-tracking-3d-design.md`

## Global Constraints

- Linking runs in **voxel coordinates**. Calibration never rewrites `z/y/x` or `link_z/y/x`; it only adds `z_um, y_um, x_um, time_s` columns and the layer's `scale`.
- Search range is `(z, y, x)` in voxels. With **Link to calibration** ticked: `isotropic_zyx(xy, pixel_size_xy_um, voxel_size_z_um) = (xy * pixel_size_xy_um / voxel_size_z_um, xy, xy)` — 4 → `(1.98, 4, 4)` on 0.104/0.210.
- Link to calibration is **off by default**; ticked with blank calibration, the run is **refused**, never silently isotropic.
- A calibration value of `None` or `0` means **unknown**; spin boxes show unknown as `0`.
- Every frame from first to last is fed to trackpy; spotless frames as **empty frames** (trackpy counts `memory` in frames fed, not `frame` values).
- Fitted centre is used only when `converged` is True and all of `fit_z/y/x` are finite; `coord_source` records `"fit"` / `"detected"` per row.
- Tracks CSV is written **once**, via `<name>.partial` + `os.replace`; a failed run leaves no partial file and keeps any earlier output.
- The track-ID column is named `particle` (as in the 2D plugin).
- Defaults: search range xy 4 px, memory 3, min track length 1, Use fitted centres on, Adaptive search off (`adaptive_stop = 0.1 * min(search_range)`, `adaptive_step = 0.95`).
- Tracking takes the process-wide one-job lock via `RunStateMixin._begin_run`, like the other widgets.
- Tests: no GPU, no real data, synthetic inputs only. Widget tests run workers synchronously through the `_launch_worker` seam; only `test_threading.py` uses real threads.
- Run all commands from the repo root, `D:\Code\Lab\spotiflow_tracking_nd`, with the venv's Python: `.venv/Scripts/python -m pytest …`.

```python
def isotropic_zyx(
    xy_value: float, pixel_size_xy_um: float, voxel_size_z_um: float
) -> tuple[float, float, float]:
    """A lateral length in voxels, as `(z, y, x)` voxels spanning the same
    physical distance on every axis.

    Voxels are rarely cubes — at 0.104 µm laterally against 0.210 µm
    axially, 4 voxels span 0.416 µm across x/y but 0.840 µm along z — so a
    σ or a search range that should be isotropic in µm needs fewer voxels
    along z. Shared by the Pre-Processing widget's Link σ and the Tracking
    widget's Link search range.
    """
    xy = float(xy_value)
    return (xy * (float(pixel_size_xy_um) / float(voxel_size_z_um)), xy, xy)
```

```python
"""Link the detection pass's spots into 3D tracks — logic only, no Qt.

The detection CSV holds one row per spot per timepoint, in voxel
coordinates. Linking runs in those same voxel coordinates, with a
per-axis search range so an anisotropic voxel does not make the range
anisotropic in µm; physical units are added afterwards, as extra columns,
never by rewriting the coordinates linking used.
"""
from __future__ import annotations

import numpy as np
import pandas as pd

#: Columns a detection CSV must have to be linked.
REQUIRED_COLUMNS = ("frame", "z", "y", "x")
#: The Gaussian-fit centre, present when detection ran with fitting on.
FIT_COLUMNS = ("fit_z", "fit_y", "fit_x")
#: The coordinates linking actually uses, chosen per row.
LINK_COLUMNS = ("link_z", "link_y", "link_x")


def missing_columns(df: pd.DataFrame) -> list[str]:
    """The `REQUIRED_COLUMNS` that `df` lacks, in order."""
    return [c for c in REQUIRED_COLUMNS if c not in df.columns]


def choose_link_coordinates(df: pd.DataFrame, use_fit: bool = True) -> pd.DataFrame:
    """Add `link_z/y/x` and `coord_source` to a copy of `df`.

    A row links on its fitted centre only when fitting is wanted, the fit
    converged, and all three fitted values are finite; otherwise on
    Spotiflow's detected `z, y, x`. The original columns are untouched.
    """
    out = df.copy()
    # `copy=True`: under pandas copy-on-write `to_numpy` may hand back a
    # read-only view, and the fitted rows are written into this array.
    coords = out[["z", "y", "x"]].to_numpy(dtype=float, copy=True)
    source = np.full(len(out), "detected", dtype=object)
    if use_fit and all(c in out.columns for c in FIT_COLUMNS) and "converged" in out.columns:
        fitted = out[list(FIT_COLUMNS)].to_numpy(dtype=float, copy=True)
        # `.eq(True)`, not `.astype(bool)`: a blank cell reads back as NaN,
        # and `bool(nan)` is True — a missing fit would count as converged.
        ok = out["converged"].eq(True).to_numpy() & np.isfinite(fitted).all(axis=1)
        coords[ok] = fitted[ok]
        source[ok] = "fit"
    for i, name in enumerate(LINK_COLUMNS):
        out[name] = coords[:, i]
    out["coord_source"] = source
    return out


def filter_short_tracks(df: pd.DataFrame, min_length: int) -> pd.DataFrame:
    """Drop tracks with fewer than `min_length` spots."""
    if min_length <= 1 or df.empty:
        return df
    lengths = df.groupby("particle")["particle"].transform("size")
    return df[lengths >= min_length].reset_index(drop=True)


def flag_censored(df: pd.DataFrame, first_frame: int, last_frame: int) -> pd.DataFrame:
    """Add `censored`: True on every row of a track present at
    `first_frame` or `last_frame`, whose true lifetime is therefore
    unknown — it may have started before the series or outlived it."""
    out = df.copy()
    if out.empty:
        out["censored"] = pd.Series(dtype=bool)
        return out
    by_track = out.groupby("particle")["frame"]
    starts, ends = by_track.transform("min"), by_track.transform("max")
    out["censored"] = (starts <= first_frame) | (ends >= last_frame)
    return out


def add_physical_columns(df: pd.DataFrame, calibration: dict) -> pd.DataFrame:
    """Add `z_um, y_um, x_um, time_s` from the link coordinates — each
    only when its own calibration value is known (not None, not 0)."""
    out = df.copy()
    pixel_xy = calibration.get("pixel_size_xy_um")
    voxel_z = calibration.get("voxel_size_z_um")
    frame_s = calibration.get("frame_interval_s")
    if voxel_z:
        out["z_um"] = out["link_z"] * voxel_z
    if pixel_xy:
        out["y_um"] = out["link_y"] * pixel_xy
        out["x_um"] = out["link_x"] * pixel_xy
    if frame_s:
        out["time_s"] = out["frame"] * frame_s
    return out
```

```python
def iter_link(
    df: pd.DataFrame,
    search_range_zyx: tuple[float, float, float],
    memory: int,
    *,
    adaptive: bool = False,
    should_stop: Callable[[], bool] = lambda: False,
) -> Iterator[tuple[int, pd.DataFrame]]:
    """Link `df` (with `LINK_COLUMNS`) frame by frame, yielding
    `(frame, linked_rows)` for every frame from the first to the last.

    Frames with no spots are fed to trackpy as empty frames rather than
    skipped: trackpy counts `memory` in frames *it has seen*, so skipping
    one would let a track bridge a gap `memory` should have broken.

    `should_stop` is checked before each frame; returning True ends the
    iteration cleanly after the frames already yielded.

    Raises:
        ValueError: a region is too dense to link at this search range
            (trackpy's `SubnetOversizeException`), with what to change.
    """
    frames = df["frame"].astype(int)
    groups = {int(t): g for t, g in df.groupby(frames, sort=True)}
    if not groups:
        return
    first, last = min(groups), max(groups)
    empty = df.iloc[0:0]
    order = range(first, last + 1)

    def _feed():
        for t in order:
            if should_stop():
                return
            yield groups.get(t, empty)

    search_range = tuple(float(v) for v in search_range_zyx)
    kwargs = {}
    if adaptive:
        kwargs = {"adaptive_stop": 0.1 * min(search_range), "adaptive_step": 0.95}

    # trackpy otherwise logs a line per frame — 349 of them per run.
    tp.quiet()
    try:
        linked = tp.link_df_iter(
            _feed(),
            search_range=search_range,
            memory=memory,
            pos_columns=list(LINK_COLUMNS),
            t_column="frame",
            **kwargs,
        )
        for t, frame_df in zip(order, linked):
            yield t, frame_df
    except SubnetOversizeException as exc:
        raise ValueError(
            "Too many candidate links in a dense region to solve at this "
            "search range — lower the search range, or tick Adaptive search."
        ) from exc
```

```python
class TrackingWorker3D(QThread):
    """Link a detection CSV into tracks, one frame at a time, and write
    the tracks CSV once linking is done.

    Written once at the end, not appended per frame like detection: the
    min-length filter and the `censored` flag both need each track whole.
    It goes to a `.partial` file first and is renamed into place, so a
    failed run never leaves a valid-looking half table — nor destroys a
    previous run's output under the same name.

    Cancellation (`cancel()`) is checked between frames. The frames linked
    so far are still filtered, flagged and written, with the last frame
    linked treated as the end of the series.
    """

    progress = Signal(int, int)  # (current, total), 1-indexed current
    # `run_finished`, not `finished` — see `VolumeOpWorker3D` for why.
    run_finished = Signal(str)   # the tracks CSV written, or "" if none
    errored = Signal(str)

    def __init__(
        self,
        csv_path: Path,
        output_path: Path,
        search_range_zyx: tuple[float, float, float],
        memory: int = 3,
        min_length: int = 1,
        use_fit: bool = True,
        adaptive: bool = False,
        calibration: dict | None = None,
        parent=None,
    ):
        super().__init__(parent)
        self._csv_path = Path(csv_path)
        self._output_path = Path(output_path)
        self._search_range_zyx = tuple(search_range_zyx)
        self._memory = memory
        self._min_length = min_length
        self._use_fit = use_fit
        self._adaptive = adaptive
        self._calibration = dict(calibration or {})
        self._cancelled = False

    def cancel(self):
        self._cancelled = True

    def run(self):
        partial = self._output_path.with_name(self._output_path.name + ".partial")
        try:
            spots = pd.read_csv(self._csv_path)
            missing = missing_columns(spots)
            if missing:
                raise ValueError(
                    f"{self._csv_path.name} is not a detection CSV — missing "
                    f"column(s): {', '.join(missing)}."
                )
            if spots["frame"].nunique() < 2:
                raise ValueError(
                    "Spots are needed in at least two timepoints to link "
                    "anything into tracks."
                )
            spots = choose_link_coordinates(spots, use_fit=self._use_fit)

            first = int(spots["frame"].min())
            total = int(spots["frame"].max()) - first + 1
            linked, last_linked = [], None
            for t, frame_df in iter_link(
                spots, self._search_range_zyx, self._memory,
                adaptive=self._adaptive,
                should_stop=lambda: self._cancelled,
            ):
                if len(frame_df):
                    linked.append(frame_df)
                last_linked = t
                self.progress.emit(t - first + 1, total)

            if not linked:
                # Cancelled before a single spot was linked: nothing to
                # write, and the caller must not mistake an older file of
                # the same name for this run's output.
                self.run_finished.emit("")
                return

            tracks = pd.concat(linked, ignore_index=True)
            tracks = filter_short_tracks(tracks, self._min_length)
            tracks = flag_censored(tracks, first, last_linked)
            tracks = add_physical_columns(tracks, self._calibration)
            tracks.to_csv(partial, index=False)
            os.replace(partial, self._output_path)
            self.run_finished.emit(str(self._output_path))
        except Exception as exc:
            partial.unlink(missing_ok=True)
            self.errored.emit(str(exc))
```

```python
"""Small Qt/napari helpers shared by the plugin's widgets."""
from __future__ import annotations

from typing import Callable


def refresh_layer_combo(combo, viewer, layer_type, predicate: Callable | None = None) -> list[str]:
    """Repopulate `combo` with the names of `viewer`'s layers of
    `layer_type` (and, if given, passing `predicate`).

    The current selection is kept when that layer is still listed. Signals
    are blocked throughout: a refresh is triggered by layers being added
    or removed anywhere in the viewer, and a host listening for the user
    choosing a layer must not mistake it for a choice.
    """
    current = combo.currentText()
    names = [
        layer.name for layer in viewer.layers
        if isinstance(layer, layer_type) and (predicate is None or predicate(layer))
    ]
    was_blocked = combo.blockSignals(True)
    try:
        combo.clear()
        combo.addItems(names)
        if current in names:
            combo.setCurrentText(current)
    finally:
        combo.blockSignals(was_blocked)
    return names
```

```python
        layout.addStretch()

        self._init_run_state(
            run_buttons=[self._run_btn],
            cancel_button=self._cancel_btn,
            progress_bar=self._progress_bar,
            status_label=self._status_label,
        )
        self._update_z_range()

    def _connect_events(self):
        self.viewer.layers.events.inserted.connect(self._refresh_points_combo)
        self.viewer.layers.events.removed.connect(self._refresh_points_combo)
        self._points_combo.currentTextChanged.connect(self._on_points_layer_chosen)
        for spin in (self._search_range_xy_spin, self._pixel_size_xy_spin, self._voxel_size_z_spin):
            spin.valueChanged.connect(self._update_z_range)
        self._link_calibration_check.toggled.connect(self._update_z_range)
        self._refresh_points_combo()

    # ── input ────────────────────────────────────────────────────────

    def _refresh_points_combo(self, event=None):
        refresh_layer_combo(
            self._points_combo, self.viewer, napari.layers.Points,
            predicate=lambda layer: bool(layer.metadata.get("csv_path")),
        )
        # The refresh is silent (see `refresh_layer_combo`), so the first
        # spots layer is adopted here — but only into an empty input: a
        # layer added elsewhere must not replace a CSV the user browsed to.
        if not self._csv_path_edit.text() and self._points_combo.currentText():
            self._on_points_layer_chosen(self._points_combo.currentText())

    def _on_points_layer_chosen(self, name: str):
        if not name or name not in self.viewer.layers:
            return
        layer = self.viewer.layers[name]
        self._set_input_csv(layer.metadata["csv_path"], layer)

    def _browse_input_csv(self):
        path, _ = QFileDialog.getOpenFileName(self, "Open detection CSV", "", "CSV files (*.csv)")
        if path:
            self._set_input_csv(path)

    def _browse_output_csv(self):
        path, _ = QFileDialog.getSaveFileName(
            self, "Save tracks CSV", self._output_path_edit.text(), "CSV files (*.csv)"
        )
        if path:
            self._output_path_edit.setText(path)

    def _set_input_csv(self, csv_path, layer=None):
        """Make `csv_path` the input: default the output beside it and
        prefill calibration — the layer's values first, then the CSV's
        sidecar, else blank."""
        self._source_layer = layer
        self._csv_path_edit.setText(str(csv_path))
        self._output_path_edit.setText(str(default_tracks_path(csv_path)))

        from_sidecar = read_sidecar_calibration(csv_path)
        from_layer = layer.metadata if layer is not None else {}
        calibration = {k: from_layer.get(k) or from_sidecar.get(k) for k in CALIBRATION_KEYS}
        self._pixel_size_xy_spin.setValue(calibration["pixel_size_xy_um"] or 0.0)
        self._voxel_size_z_spin.setValue(calibration["voxel_size_z_um"] or 0.0)
        self._frame_interval_spin.setValue(calibration["frame_interval_s"] or 0.0)

        try:
            frames = pd.read_csv(csv_path, usecols=["frame"])["frame"]
        except (OSError, ValueError) as exc:
            self._csv_info_label.setText(f"Cannot read this CSV: {exc}")
        else:
            self._csv_info_label.setText(
                f"{len(frames)} spots across {frames.nunique()} timepoints."
            )

    # ── parameters ───────────────────────────────────────────────────

    def _calibration(self) -> dict:
        return {
            "pixel_size_xy_um": self._pixel_size_xy_spin.value() or None,
            "voxel_size_z_um": self._voxel_size_z_spin.value() or None,
            "frame_interval_s": self._frame_interval_spin.value() or None,
        }

    def _update_z_range(self, *_):
        linked = self._link_calibration_check.isChecked()
        self._search_range_z_spin.setEnabled(not linked)
        calibration = self._calibration()
        if linked and calibration["pixel_size_xy_um"] and calibration["voxel_size_z_um"]:
            self._search_range_z_spin.setValue(isotropic_zyx(
                self._search_range_xy_spin.value(),
                calibration["pixel_size_xy_um"],
                calibration["voxel_size_z_um"],
            )[0])

    def _search_range_zyx(self) -> tuple[float, float, float] | None:
        """The `(z, y, x)` search range in voxels, or None (after
        `show_error`) when linked to a calibration that is blank.

        Computed here, not read back from the z box: the box rounds to two
        decimals, and linking should use the exact ratio.
        """
        xy = self._search_range_xy_spin.value()
        if not self._link_calibration_check.isChecked():
            return (self._search_range_z_spin.value(), xy, xy)
        calibration = self._calibration()
        if not calibration["pixel_size_xy_um"] or not calibration["voxel_size_z_um"]:
            show_error(
                "The search range is linked to calibration, but the pixel and "
                "voxel sizes are blank — fill them in, or untick Link to "
                "calibration."
            )
            return None
        return isotropic_zyx(xy, calibration["pixel_size_xy_um"], calibration["voxel_size_z_um"])

    # ── run ──────────────────────────────────────────────────────────

    def _run_tracking(self):
        csv_text = self._csv_path_edit.text().strip()
        if not csv_text:
            show_error("No detection CSV selected.")
            return
        csv_path = Path(csv_text)
        if not csv_path.is_file():
            show_error(f"Detection CSV not found: {csv_path}")
            return
        out_text = self._output_path_edit.text().strip()
        if not out_text:
            show_error("No output path for the tracks CSV.")
            return
        out_path = Path(out_text)
        if same_file(csv_path, out_path):
            show_error(
                "The tracks CSV would overwrite the detection CSV — pick a "
                "different output path."
            )
            return
        search_range = self._search_range_zyx()
        if search_range is None:
            return

        calibration = self._calibration()
        record = {
            **calibration,
            "search_range_zyx": [float(v) for v in search_range],
            "link_to_calibration": self._link_calibration_check.isChecked(),
            "memory": self._memory_spin.value(),
            "min_length": self._min_length_spin.value(),
            "use_fit": self._use_fit_check.isChecked(),
            "adaptive": self._adaptive_check.isChecked(),
            "source_csv": str(csv_path),
            "trackpy_version": trackpy.__version__,
        }
        source_layer = self._source_layer
        if source_layer is not None and (
            source_layer not in self.viewer.layers
            or not same_file(source_layer.metadata.get("csv_path", ""), csv_path)
        ):
            source_layer = None
        name_base = source_layer.name if source_layer is not None else csv_path.stem

        worker = TrackingWorker3D(
            csv_path=csv_path,
            output_path=out_path,
            search_range_zyx=search_range,
            memory=record["memory"],
            min_length=record["min_length"],
            use_fit=record["use_fit"],
            adaptive=record["adaptive"],
            calibration=calibration,
        )

        def _on_finished(written: str):
            if not written:
                show_info("Tracking stopped before any spot was linked — nothing written.")
                return
            sidecar = calibration_sidecar_path(written)
            try:
                sidecar.write_text(json.dumps(record, indent=2), encoding="utf-8")
            except OSError as exc:
                show_error(f"Could not write the tracking sidecar {sidecar}: {exc}")
            tracks = pd.read_csv(written)
            if tracks.empty:
                show_info("No tracks left after the minimum-length filter.")
                return
            self._add_tracks_layer(
                tracks,
                name=f"{name_base} (tracks){self.cancelled_suffix()}",
                calibration=calibration,
                source_layer=source_layer,
                csv_path=written,
            )

        self._summary = ""
        # The frame count is only known once the worker has read the CSV;
        # its first `progress` sets the bar's maximum.
        self._begin_run(worker, total=0, description="Linking tracks", on_finished=_on_finished)

    def _add_tracks_layer(self, tracks, *, name, calibration, source_layer, csv_path):
        # napari reorders Tracks rows by (track, time) internally; sorting
        # first keeps `features` aligned with the rows they describe.
        tracks = tracks.sort_values(["particle", "frame"], kind="stable").reset_index(drop=True)
        data = tracks[["particle", "frame", *LINK_COLUMNS]].to_numpy(dtype=float)
        if calibration["pixel_size_xy_um"] and calibration["voxel_size_z_um"]:
            scale = compute_layer_scale(
                calibration["pixel_size_xy_um"], calibration["voxel_size_z_um"]
            )
        elif source_layer is not None:
            scale = tuple(source_layer.scale)
        else:
            scale = (1.0, 1.0, 1.0, 1.0)
        features = tracks[[c for c in FEATURE_COLUMNS if c in tracks.columns]]
        self.viewer.add_tracks(
            data,
            name=name,
            scale=scale,
            features=features,
            metadata={"tracks_csv_path": csv_path, **calibration},
        )
        n_censored = tracks.loc[tracks["censored"], "particle"].nunique()
        self._summary = (
            f"{tracks['particle'].nunique()} tracks, {len(tracks)} spots, "
            f"{n_censored} censored, across {tracks['frame'].nunique()} frames."
        )
        show_info(self._summary)

    def _on_run_finished(self, payload=None):
        # The mixin writes "Done." / "Cancelled at …" after the host's
        # handler; the summary goes after that so it is what stays visible.
        super()._on_run_finished(payload)
        if self._summary:
            self._set_status(f"{self._status_label.text()} {self._summary}")
```

```
### Tracking search range

Linking runs in voxels, so the search range has the same problem as σ: 4
voxels is 0.416 µm across x/y but 0.840 µm along z, and an isotropic
4-voxel range lets a spot jump twice as far axially as laterally. Tick
**Link to calibration** and the z range is derived from the xy one,

```
z = xy × (pixel_size_xy_um / voxel_size_z_um)
```

so 4 px becomes `(1.98, 4, 4)` — the same 0.416 µm on every axis. Unticked,
the z range is whatever you type. Linked with blank calibration, the run
is refused. The calibration fields prefill from the spots layer, then the
detection CSV's sidecar; fill them in by hand for a series detected
before calibration was applied.

**Memory** is counted in timepoints, including timepoints with no spots
at all. **Min track length** defaults to 1 — short-lived structures are
data for lifetime analysis, not noise to drop by default.
```
